# ZenAudioSynth

[简体中文](README.zh-CN.md)

Turn natural materials into a playable sound garden.

![ZenAudioSynth cover](docs/cover.png)

**[Live version](https://onovich.github.io/ZenAudioSynth/)**

## What it includes

- Five presets.
- Tone.js synthesis.
- Fluid visuals.

## Getting started

Install dependencies and start the local version:

```bash
npm install
npm run dev
```

The repository also provides `npm run build`.

## Repository map

- `src/` — Application and library source.
- `origin/` — Original prototype and design material.
- `.github` — Automation and GitHub Pages workflows.
- `index.html` — Web entry point.
- `package.json` — Package scripts and dependencies.
